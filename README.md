#### Kotlin backend projects

- **[Yedu](https://www.yedu.ae/)** (ride-hailing platform with an AI assistant): Kotlin / Spring Boot backend for booking by text, voice or photo, fixed fares, airport transfers, and driver earnings and route tracking. The mobile app is built with Kotlin Multiplatform.
- **[Kerwen](https://kerwen.online/)** (online store for household goods): Kotlin / Spring Boot backend behind the website and the [Android](https://play.google.com/store/apps/details?id=com.meransoft.commerce) and [iOS](https://apps.apple.com/tm/app/kerwen/id6788402200) apps. It handles the catalog by category and brand, cart, delivery or pickup with time slots, and order statuses.

#### Open-source Kotlin projects

- **[shop-api](https://github.com/al-fara-bi/shop-api)**: online store backend with JWT auth, catalog, cart, and checkout with delivery slots, stock control and an order state machine. Spring Boot 4, PostgreSQL, Flyway, Testcontainers.
- **[tmcars-crawler](https://github.com/al-fara-bi/tmcars-crawler)**: polite crawler for Turkmen car listings (robots.txt, throttling, retries) with price history and a search / price-statistics API. Spring Boot 4, Jsoup, PostgreSQL.

#### How I build backends

- Layered Spring Boot services (controller → service → repository) with DTO validation
- Versioned database migrations with Flyway
- JWT authentication
- Containerized with Docker and deployed to VPS
